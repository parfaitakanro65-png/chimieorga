Guide d'utilisation

Une ressource de découverte et de révision en chimie organique.

1. Comprendre une molécule

La formule brute indique les types et nombres d'atomes. La formule semi-développée montre une partie de leur organisation. Les liaisons représentent les connexions entre les atomes.

Exemple : CH₃–CH₂–OH est la formule semi-développée de l'éthanol.

2. Reconnaître une famille

  • Alcool : groupe hydroxyle –OH.
  • Acide carboxylique : groupe –COOH.
  • Cétone : groupe carbonyle C=O entre deux carbones.
  • Alcène : au moins une double liaison C=C.
  • Ester : groupe caractéristique –COO–.
  • Glucide : famille comprenant notamment les sucres.

3. Comprendre une réaction

Les réactifs sont les substances de départ. Une transformation chimique réorganise les atomes pour former des produits. Une équation correctement équilibrée conserve le nombre d'atomes de chaque élément.

4. Limites du laboratoire virtuel

Les dessins moléculaires sont des schémas 2D simplifiés et non des modèles 3D calculés. Les équations sont pédagogiques : les conditions réelles, les rendements et les réactions secondaires ne sont pas modélisés.

Ne réalisez pas de réaction chimique à la maison sur la seule base de cette application. Certaines substances sont inflammables, corrosives ou toxiques.
